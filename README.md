# Quizzy

Quizzy is a clean and interactive quiz app built with React and Next.js, showcasing smooth UI, fast performance, and a fully client-side design.

---

## 🧠 Overview

This project was developed as part of a personal portfolio to demonstrate:
- Building interactive applications using Next.js
- Creating smooth and responsive user flows
- Designing engaging UI experiences with animations
- Structuring scalable frontend projects

The application is designed to be flexible and easily extendable for different quiz-based use cases.
